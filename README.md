# Application source

All application code belongs under this directory. Agent definitions and project documentation remain in the outer Nexora workspace root.

## Folder structure

- [backend](./backend/) — FastAPI Python server with REST API under `/api/v1`
- [frontend](./frontend/) — React + TypeScript SPA with Vite dev server
- [infra](./infra/) — Docker configuration, database migrations, deployment scripts
- [tests-e2e](./tests-e2e/) — Playwright end-to-end test suite
